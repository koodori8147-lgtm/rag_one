# LangChain Memory 정리

> 실행 환경 기준: `langchain==1.4.1`, `langchain-classic==1.0.8`, `langchain-community==0.4.2`, `langchain-openai==1.6.2`
>
> 최신 LangChain(1.x)에서는 아래 Memory 클래스들이 `langchain` 패키지가 아니라 **`langchain_classic.memory`** (구 `langchain.memory`) 및 **`langchain_community.memory`** 로 이동했습니다. 이 문서의 import는 위 버전 조합에서 실제로 동작 확인한 코드입니다.
>
> ⚠️ 공식적으로는 이 레거시 Memory 클래스들은 deprecated 상태이며, 신규 프로젝트는 LangGraph의 checkpointer/Store 기반 메모리를 권장합니다. 다만 학습·기존 코드 호환 목적으로는 아래 클래스들을 그대로 사용할 수 있습니다.

## 공통 준비 코드

```python
from dotenv import load_dotenv
load_dotenv()

from langchain_openai import ChatOpenAI

llm = ChatOpenAI(model="gpt-4o-mini", temperature=0)
```

---

## 1. ConversationBufferMemory

**핵심 개념**: 대화 내용을 가공 없이 전체 그대로 문자열(또는 메시지 리스트)로 저장하는 가장 단순한 메모리. 대화가 길어질수록 프롬프트에 포함되는 토큰 수가 계속 늘어난다는 단점이 있다.

📄 공식 문서: [ConversationBufferMemory | langchain_classic API Reference](https://reference.langchain.com/python/langchain-classic/memory/buffer/ConversationBufferMemory)

```python
from langchain_classic.memory import ConversationBufferMemory

memory = ConversationBufferMemory()

memory.save_context(
    {"input": "안녕하세요, 저는 김철수입니다."},
    {"output": "안녕하세요 철수님! 무엇을 도와드릴까요?"},
)

print(memory.load_memory_variables({}))
# {'history': 'Human: 안녕하세요, 저는 김철수입니다.\nAI: 안녕하세요 철수님! 무엇을 도와드릴까요?'}

# 메시지 객체 리스트로 받고 싶다면
memory = ConversationBufferMemory(return_messages=True)
```

## 2. ConversationBufferWindowMemory

**핵심 개념**: `ConversationBufferMemory`와 동일하지만 최근 `k`개의 대화 턴(turn)만 유지하고 오래된 대화는 버린다. 토큰 사용량을 제한하면서 최신 문맥을 유지하고 싶을 때 사용.

📄 공식 문서: [ConversationBufferWindowMemory | langchain_classic API Reference](https://reference.langchain.com/python/langchain-classic/memory/buffer_window/ConversationBufferWindowMemory)

```python
from langchain_classic.memory import ConversationBufferWindowMemory

memory = ConversationBufferWindowMemory(k=2, return_messages=False)

memory.save_context({"input": "1번째 질문"}, {"output": "1번째 답변"})
memory.save_context({"input": "2번째 질문"}, {"output": "2번째 답변"})
memory.save_context({"input": "3번째 질문"}, {"output": "3번째 답변"})

print(memory.load_memory_variables({}))
# k=2 이므로 가장 오래된 "1번째" 대화는 제외되고 최근 2턴만 남음
```

## 3. ConversationTokenBufferMemory

**핵심 개념**: 대화를 저장하되, 전체 토큰 수가 `max_token_limit`을 넘으면 오래된 대화부터 잘라낸다. 턴(turn) 개수가 아니라 **토큰 수** 기준으로 자르기 때문에 모델의 컨텍스트 길이 제한에 맞춰 관리하기 좋다. 토큰 계산을 위해 `llm` 객체가 필요하다.

📄 공식 문서: [ConversationTokenBufferMemory | langchain_classic API Reference](https://reference.langchain.com/python/langchain-classic/memory/token_buffer/ConversationTokenBufferMemory)

```python
from langchain_classic.memory import ConversationTokenBufferMemory

memory = ConversationTokenBufferMemory(llm=llm, max_token_limit=150)

memory.save_context(
    {"input": "인공지능 모델의 종류를 알려주세요."},
    {"output": "대표적으로 CNN, RNN, Transformer 기반 모델 등이 있습니다."},
)
memory.save_context(
    {"input": "Transformer에 대해 더 설명해주세요."},
    {"output": "Transformer는 Self-Attention 구조를 기반으로 한 모델입니다."},
)

print(memory.load_memory_variables({}))
```

## 4. ConversationEntityMemory

**핵심 개념**: 대화에서 언급된 **개체(Entity, 사람·장소·사물 등)** 를 LLM으로 추출하고, 각 개체에 대한 요약 정보를 별도로 축적·관리한다. "누가 누구인지", "무엇이 무엇인지" 같은 개체 중심 정보를 장기적으로 추적할 때 유용.

📄 공식 문서: [ConversationEntityMemory | langchain_classic API Reference](https://reference.langchain.com/python/langchain-classic/memory/entity/ConversationEntityMemory)

```python
from langchain_classic.memory import ConversationEntityMemory
from langchain_classic.memory.prompt import ENTITY_MEMORY_CONVERSATION_TEMPLATE

memory = ConversationEntityMemory(llm=llm)

memory.save_context(
    {"input": "철수는 삼성전자에서 근무하는 개발자입니다."},
    {"output": "철수님은 삼성전자 개발자시군요! 어떤 프로젝트를 하시나요?"},
)

# 특정 입력과 관련된 엔티티 요약을 조회
print(memory.load_memory_variables({"input": "철수는 어디서 일하나요?"}))
# {'history': '...', 'entities': {'철수': '철수는 삼성전자에서 근무하는 개발자이다.'}}
```

## 5. ConversationKGMemory (Knowledge Graph Memory)

**핵심 개념**: 대화 내용을 `(주어, 관계, 목적어)` 형태의 **triple**로 추출해 지식 그래프(Knowledge Graph)로 저장한다. 개체 간의 **관계**까지 구조화해서 관리하고 싶을 때 사용하며, 내부적으로 `networkx` 그래프를 사용한다.

> `langchain_community.memory.kg` 는 `networkx` 패키지가 필요하다: `pip install networkx`

📄 공식 문서: [ConversationKGMemory | langchain_community API Reference](https://reference.langchain.com/python/langchain-community/memory/kg/ConversationKGMemory)

```python
from langchain_community.memory.kg import ConversationKGMemory

memory = ConversationKGMemory(llm=llm)

memory.save_context(
    {"input": "철수는 영희의 남편입니다."},
    {"output": "그렇군요, 철수님과 영희님은 부부시군요."},
)

# 특정 엔티티에 대해 알고 있는 triple 조회
print(memory.load_memory_variables({"input": "철수는 누구입니까?"}))

# 그래프에 저장된 triple 직접 확인
print(memory.kg.get_triples())
```

## 6. ConversationSummaryMemory

**핵심 개념**: 대화가 진행될 때마다 LLM을 이용해 지금까지의 대화를 **요약본**으로 계속 갱신하며 저장한다. 원문 전체를 저장하지 않으므로 긴 대화에서도 프롬프트 토큰 사용량이 크게 늘지 않는다.

📄 공식 문서: [ConversationSummaryMemory | langchain_classic API Reference](https://reference.langchain.com/python/langchain-classic/memory/summary/ConversationSummaryMemory)

```python
from langchain_classic.memory import ConversationSummaryMemory

memory = ConversationSummaryMemory(llm=llm)

memory.save_context(
    {"input": "오늘 회의에서 신제품 출시 일정을 논의했습니다."},
    {"output": "네, 다음 달 15일 출시로 결정되었다고 들었습니다."},
)
memory.save_context(
    {"input": "마케팅 예산도 함께 정해졌나요?"},
    {"output": "네, 5천만원으로 책정되었습니다."},
)

print(memory.load_memory_variables({}))
# {'history': '(LLM이 생성한 대화 요약문)'}
```

## 7. VectorStoreRetrieverMemory

**핵심 개념**: 대화 내용을 벡터스토어(Vector DB)에 임베딩으로 저장해두고, 새로운 질문이 들어오면 **의미적으로 가장 유사한 과거 대화**를 검색해 꺼내온다. 시간 순서가 아니라 **관련성** 기준으로 문맥을 불러오기 때문에 대화가 아주 길거나 오래된 정보도 찾아올 수 있다.

> FAISS를 사용하려면 `pip install faiss-cpu` 필요 (Chroma 등 다른 벡터스토어로 대체 가능)

📄 공식 문서: [VectorStoreRetrieverMemory | langchain_classic API Reference](https://reference.langchain.com/python/langchain-classic/memory/vectorstore/VectorStoreRetrieverMemory)

```python
import faiss
from langchain_community.docstore.in_memory import InMemoryDocstore
from langchain_community.vectorstores import FAISS
from langchain_openai import OpenAIEmbeddings
from langchain_classic.memory import VectorStoreRetrieverMemory

embeddings = OpenAIEmbeddings(model="text-embedding-3-small")

# 빈 FAISS 인덱스 생성
embedding_size = 1536
index = faiss.IndexFlatL2(embedding_size)
vectorstore = FAISS(embeddings, index, InMemoryDocstore({}), {})

retriever = vectorstore.as_retriever(search_kwargs={"k": 1})
memory = VectorStoreRetrieverMemory(retriever=retriever)

memory.save_context({"input": "제가 가장 좋아하는 음식은 피자입니다."}, {"output": "좋아하시는군요!"})
memory.save_context({"input": "제가 사는 도시는 서울입니다."}, {"output": "서울에 거주하시는군요!"})

# 질문과 의미적으로 유사한 과거 대화만 검색되어 반환됨
print(memory.load_memory_variables({"prompt": "이 사람이 좋아하는 음식은 무엇인가요?"}))
```

## 요약 비교표

| 클래스 | 저장 방식 | LLM 필요 여부 | 특징 |
|---|---|---|---|
| ConversationBufferMemory | 전체 원문 | 불필요 | 가장 단순, 토큰 증가에 취약 |
| ConversationBufferWindowMemory | 최근 k턴 원문 | 불필요 | 최신 대화만 유지 |
| ConversationTokenBufferMemory | 토큰 한도 내 원문 | 필요(토큰 계산용) | 토큰 기준으로 컷 |
| ConversationEntityMemory | 개체별 요약 | 필요 | 개체(사람/사물) 중심 추적 |
| ConversationKGMemory | (주어,관계,목적어) triple | 필요 | 관계 기반 지식 그래프 |
| ConversationSummaryMemory | 누적 요약문 | 필요 | 긴 대화에 효율적 |
| VectorStoreRetrieverMemory | 임베딩 벡터 | 불필요(임베딩 모델만) | 의미 유사도 기반 검색 |
